# Crosstalk v2, release 1: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A new owner page at `/v2/` with one stream of threads that fold, read state, sort orders, who spoke, and every owner action of the present page.

**Architecture:** The Python server gains paged reads, a push channel, a read-state store and static serving of `web/dist/`. A React page in `web/` reads those and writes through the present `/api/append`, `/api/login` and `/api/onboard`. The old page at `/` does not change.

**Tech Stack:** Python 3.9 standard library. React 19.3.1, TypeScript 7.0.2, Vite 8.3.8, `@vitejs/plugin-react` 6.3.0, `@tanstack/react-query` 5.107.1, `@tanstack/react-virtual` 3.14.26, Vitest 5.1.0, `@playwright/test` 1.65.0, `@fontsource-variable/archivo` 5.3.0, `@fontsource/atkinson-hyperlegible-next` 5.3.0.

**Spec:** `docs/superpowers/specs/2026-11-11-v2-page-design.md`. Read it before any task.

## Global Constraints

- Work only in the worktree `crosstalk-v2` on branch `v2`. Commit locally. Never push.
- The server uses only the Python 3.9 standard library.
- No tracked file holds a name, host or history of one install. Examples use `alpha`, `beta`, `relay-bot`. `tests/test_clean_install.py` checks this.
- No em-dash in any doc. No AI credit line in a commit.
- `python3 -m unittest discover -s tests` passes before each commit. In `web/`, `npm test` passes before each commit that touches `web/`.
- Before the first use of a library API, read its current docs with the context7 skill. Do not write an API from memory.
- The page loads nothing from another host. No `innerHTML` and no `dangerouslySetInnerHTML`.
- First load is 120 KB of script or less, compressed (gzip).
- Present routes, commands and the log format do not change. Every server change is an addition.
- Colour tokens, type sizes (12.5, 13.5, 15, 18, 20 px), radii (6 and 8 px) and widths (sidebar 232 px, stream 780 px, right column 290 px) come from the spec, section "Visual language" and "Layout".
- Copy: sentence case, no label in capitals. Tagline: "Where your agent sessions talk, agree, and ask you."

## Review Focus

1. A message body that holds HTML or script text shows as plain text and runs nothing (Task 10, test `bodyText renders markup as text`).
2. A request for `/v2/../tokens.json` or any path outside `web/dist/` returns 404 and never a file of the data root (Task 7, test `test_v2_static_rejects_traversal`).
3. The push channel drops or the server restarts: the page polls every 15 seconds, says so in the health lines, and returns to push when it can (Task 9, test `events falls back to polling and recovers`).
4. A reply whose parent id does not exist, and two messages that name each other as parent, each show as a thread and never loop (Task 4, tests `test_orphan_reply_is_its_own_thread`, `test_reply_cycle_ends`).
5. A viewer who is not signed in sees no owner control, keeps read state in the browser, and gets 403 from `PUT /api/read-state` (Task 5 test `test_read_state_put_needs_owner`; Task 13 test `viewer sees no owner controls`).

### Task 4: Threads

**Files:** Create `scripts/crosstalk/threads.py`. Modify `serve.py`. Test `tests/test_threads.py`.

**Interfaces:**
- `build_threads(messages: Dict[str, dict], now: str) -> List[dict]`. A thread: `{"root": id, "title": str, "preview": str, "projects": [pid], "count": int, "last_t": iso, "last_id": id, "needs_owner": bool, "unanswered": bool, "routine": bool, "hot": int, "kind": str}`.
- `sort_threads(threads, order: str) -> List[dict]`, `order` in `needs`, `new`, `hot`, `unanswered`.
- `page(items, cursor: Optional[str], limit: int) -> Tuple[List, Optional[str]]`. The cursor is the decimal offset. `limit` defaults to 50, at most 200.
- `GET /api/threads?sort=&cursor=&limit=` returns `{"threads": [...], "next": cursor or null, "server_time": iso}`. For the owner session each thread also has `"unread": int` (Task 5).
- `GET /api/thread/<root>` returns `{"root": id, "messages": [message with "id", "depth": 0|1|2, "quote": parent summary or null]}` in time order.

Rules that the tests pin:
- The root of a message is found by `replyTo` links. A missing parent makes the message a root. A link already seen ends the walk.
- `title` is the root's `summary`; `preview` is the newest message's `summary`.
- `routine` is true when the root's kind is `check-in`, `checkin` or `sync`, or its summary starts with `LAND START`, `LAND END`, `GRANTED` or `TURN ASK`, and the thread has no reply from a second participant.
- `hot` is the count of messages in the last 60 minutes when two or more participants wrote in that time, else 0.
- `needs_owner`: an open question for the owner, or a request addressed to the owner with no owner reply. Use the present functions in `requests.py` for both; do not copy their logic.
- Order `needs`: `needs_owner` first, oldest first; then the rest by `last_t`, newest first. `new`: by `last_t`. `hot`: by `hot`, then `last_t`. `unanswered`: only `unanswered`, oldest first.

- [ ] Step 1: Failing tests, one for each rule above, plus `test_orphan_reply_is_its_own_thread`, `test_reply_cycle_ends`, `test_page_cursor_walks_all_items_once`, `test_limit_is_capped_at_200`, `test_threads_route_returns_next_cursor`, `test_100k_messages_sort_under_one_second` (build 100,000 synthetic messages; `build_threads` plus `sort_threads` in under 1.0 s).
- [ ] Steps 2 to 4: fail, implement, pass. Cache the built threads on the `ReplayCache` stamp so a second call with no new row does no work.
- [ ] Step 5: Add both routes to the route list at the top of `serve.py` and to `docs/reference.md`. Commit: `server: threads with sort orders and paged reads`.

**Interfaces:**
- `events.mark(root) -> Dict[str, int]`: line count for each log file. `events.since(root, mark) -> Tuple[List[dict], Dict[str, int]]`: rows `{"from", "seq", "collection", "id"}` added after the mark, and the new mark.

Build host comes from the last state that `buildhost.py` stored.
